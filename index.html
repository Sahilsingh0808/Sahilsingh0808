Spine AI · YC S23Research platform2025 — 26

Spine — Spine Swarm

Spine is an AI research platform that orchestrates 400+ models as parallel agents to produce client-ready deliverables — decks, PDFs, Excel models with formulas — in minutes, not days. Its deep-research engine ranked #1 on Google DeepMind's DeepSearchQA benchmark (87.6% accuracy). Investors, consultants, legal, medical, and GTM teams use it to compress days of analyst work into a single run.

What I built

  • Spine Swarm orchestration engine. Architected and owned the backend coordinating 1–10 specialized agents per task — 500+ running concurrently — enabling parallel, non-sequential execution of multi-step research workflows.
  • Intelligent model router. Dynamic selection across 400+ LLMs per step, optimizing for quality, latency, and cost. Cumulative 106k+ intelligence nodes processed.
  • Canvas APIs + data layer. Powered 6,400+ active canvas environments with real-time collaborative agent execution, artifact persistence, branching, and full inspectability.
  • React canvas frontend + 0→1 product. Built the visual canvas UI, scheduled-workflow system, and integrations across MCP, webhooks, and external APIs.
  • Multi-cloud DevOps. AWS / GCP / Azure with zero-downtime blue–green deploys; reliability across hundreds of concurrent long-running agent tasks.

Why it matters

Most "AI research" tools generate chat. Spine generates deliverables — and orchestrates models per step instead of pinning the whole task to one LLM. The Swarm pattern is what makes it possible to push a research task into a parallel DAG and get back artifacts a human would otherwise spend a day producing.

EverTutor.ai
